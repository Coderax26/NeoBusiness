## 7. Current worktree warning

The worktree is not clean. The following categories contain uncommitted changes and must not be mixed into an M5 commit without review:

- M0 migration-service changes.
- M1 acceptance and DI changes.
- M6 service, migration, and test changes.
- M7a service/spec changes.
- M5 source and migrations.
- Documentation updates.
- Local/configuration files such as `.env.test`.
- `.claude/`, `.github/`, `docs/modules/`, and `graphify-out/` artifacts.

Before committing M5:

1. Review the complete diff.
2. Separate unrelated M0/M1/M6/M7a changes.
3. Exclude secrets, local configuration, generated files, and planning artifacts.
4. Run build, lint, M3/M5 tests, configured e2e tests, and `git diff --check`.
5. Stage only the reviewed M5 files and required shared integration fixes.
